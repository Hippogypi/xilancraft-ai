- [ ] 管理端已配置**真实智谱 Provider**（cogview-3-flash）且已激活、测试生成通过
- [ ] 免费额度充足（生成记录页看当日调用量）
- [ ] Mock Provider 保留但未激活（现场网络故障时 30 秒可切回保底演示流程）
- [ ] 电脑音量/网络正常（织机视频、云端生图都需联网）

## 三、现场演示脚本（约 8 分钟）

1. **文化导入**（1min）：非遗导览页——西兰卡普历史/通经断纬工艺/无字史书价值；播织机视频；符号解构案例卡讲"传统→重构"理念
2. **灵感素材**（1min）：素材库看真实纹样（四十八勾/阳雀花…含来源）；点开任一详情讲文化语义；「以此为灵感」跳工坊
3. **AI 共创（核心）**（2min）：工坊顶部已带参考纹样标签；**请评委现场出题**输入新提示词，选风格/配色/部位 → 生成 → 展示"查看提交的完整提示词"（体现重构模板工程）→ 真实AI新图
4. **服装定制**（2min）：「用此纹样」→ 定制页选连帽卫衣 → 拖动大小/位置/透明度滑杆 → 填尺码 → 勾隐私 → 提交 → 订单号 XLKP-…
5. **管理端闭环**（2min）：导览页logo连点5次 → 登录 → 订单管理找到刚才订单 → 「确认设计」→「标记完成」；展示生成记录（提示词/模型/耗时）；展示AI接口配置中心——**现场切换Provider**演示可维护性
6. **备用剧本**：网络异常时，管理端激活 Mock Provider 继续走完 3~5 步（向评委说明这是本地兜底服务，真实AI需联网）

## 四、常见问题处置

| 症状 | 处置 |
|---|---|
| 端口3000被占用 | `netstat -ano | findstr :3000` 找 PID → `taskkill /PID <pid> /F` 重启 |
| 管理端登录锁定 | 重启后端（锁定为内存态，10分钟自动解） |
| 生成报"额度用完" | 管理端切备用Provider；或调大该Provider每日上限 |
| 视频加载失败 | 确认后端进程在跑（视频走 /api/assets/loom.mp4） |
| 生图慢/超时 | cogview-3-flash 正常5~8s；超15s是小程序端超时，可稍后重试或用管理端测试生成验证服务 |
| 真机看不了 | 本Demo主环境为开发者工具模拟器；真机需改 BASE_URL 为电脑局域网IP+真机调试模式 |
