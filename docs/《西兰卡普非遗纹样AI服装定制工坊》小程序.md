# 《西兰卡普非遗纹样AI服装定制工坊》小程序开发工作指导书

**文档版本**：V4.0（商业设计融合版）
**项目赛道**：服装设计类技能大赛
**非遗主题**：土家族西兰卡普（织锦）
**核心开发人员**：张智航（技术集成与前端开发）
**编制日期**：2026年11月

## 1. 项目概述与开发目标

### 1.1 项目定位

本项目为参加“服装设计类”技能大赛的数字化应用。以土家非遗**西兰卡普**为核心，结合3D建模、TD参数化交互与AIGC技术，打造一款微信小程序。项目不仅是对传统纹样的复刻，更是**通过“符号拆解与几何重组”，将传统织锦图腾转化为现代街头/新中式服装潮流元素**，实现从“文化认知”到“AI纹样共创”，再到“服装效果预览与定制意向提交”的完整C2M业务闭环。

### 1.2 核心开发目标

负责人在本项目中承担**技术集成与前端落地**任务。需利用低代码平台（WorkBuddy）与微信云开发（CloudBase），将各成员的非遗数字化成果进行转化整合，并接入腾讯混元AI生图大模型。**核心目标是让AI能稳定生成具备现代服装设计感、可直接用于印花的“重构型非遗纹样”**，并确保小程序流程顺畅并顺利通过微信平台合规审核。

## 2. 团队协作与素材规范

为保障小程序运行性能与最终展示效果，所有复杂计算与高精度模型均需降维转化为轻量级前端素材。

### 2.1 素材交付标准表

| 协作成员         | 负责模块    | 交付素材规范要求                                                                                                                                   | 前端整合方案                                            |
| :--------------- | :---------- | :------------------------------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------ |
| **秦彬凌** | 3D织布机/VR | MP4格式视频，H.264编码，体积 ≤ 20MB。展示土家传统斜织机运作工序。                                                                                 | 嵌入小程序首页 `<video>` 组件，作为“非遗技艺导览”。 |
| **韩笑**   | TD交互变形  | GIF动图或短MP4视频。展示经纬密度调节及几何纹样的解构生成过程。                                                                                     | 嵌入“灵感教程”页面，作为AI生成的原理参考。            |
| **霍佳雪** | Style3D服装 | **现代潮牌或新中式服装** PNG高清图（透明背景）。**须预留明确的印花贴图区域，并附带该区域的相对坐标（top/left/width/height 百分比）。** | 作为“服装预览”页面的底层图层，用于叠加AI生成的纹样。  |

## 3. 小程序技术架构与功能规范

### 3.1 技术底座

* **前端搭建**：WorkBuddy（自然语言生成微信原生代码）。
* **后端服务**：微信云开发 CloudBase（云数据库、云存储）。
* **AI大模型**：腾讯混元生图模型（云开发AI扩展接入）。

### 3.2 核心功能模块（四Tab架构）

**1. 非遗导览（首页）**

* 播放秦彬凌提供的织机视频。`<video>` 组件的 `src` 和 `poster` 均支持直接传入云文件ID（fileID）。
* 图文展示西兰卡普历史，**特别强调“从传统图腾到现代潮流的演变”**。

**2. 灵感素材库**

* 从云数据库 `resources` 集合读取图片，以瀑布流展示。建议做**对比展示**：左侧为传统西兰卡普原图，右侧为经过现代几何提取、解构重组后的潮流元素图。
* 点击图片跳转AI工坊，将图片链接作为“垫图”参数传入。

**3. AI定制工坊（核心）**

* **Provider初始化**：`wx.cloud.extend.AI.createImageModel("hunyuan-image")`。`"hunyuan-image"` 是 provider。
* **文生图**：`generateImage` 的 `model` 必填 `"HY-Image-3.0-Plus-4090-Tob-v1.0"`。
* **图生图**：`model` 必填 `"HY-Image-v3.0-I2I-ToB-v1.0.1"`，垫图通过 `image_urls`（URL列表）或 `images`（纯base64，不带前缀）传入，最多1张，单张≤10MB，jpg/png。
* **尺寸**：默认 `1024x1024`。
* **超时**：`timeout: 120000` 必须在 `generateImage` 中显式设置。
* **Prompt策略（重点升级）**：提示词必须引导AI进行“设计重构”，而非单纯复刻。示例：“*解构西兰卡普传统鸟纹，转化为极简几何徽章Logo，街头潮流风格，扁平化，适合作为现代服装胸前印花。*”

**4. 服装预览与意向单**

* **预览**：将AI生成的纹样通过绝对定位叠加在霍佳雪提供的现代服装PNG图上，使用 `opacity` 调节透明度，模拟印花效果。
* **表单**：收集用户姓名、联系方式及当前设计的纹样链接，写入云数据库 `orders` 集合。
* **合规**：表单必须包含用户主动勾选的《隐私政策》勾选框，不能默认勾选；后台配置《用户隐私保护指引》。

# 附录：关键模块实现方法

## A. AI定制工坊：文生图与图生图的完整调用

### A.1 前置条件

基础库版本 ≥ 3.17.4，且 CloudBase 环境已完成初始化。未初始化直接调用会报错。

### A.2 文生图实现

`createImageModel("hunyuan-image")` 中的 `"hunyuan-image"` 是 **provider**，真正决定效果的是 `model` 参数。

```javascript
const imageModel = wx.cloud.extend.AI.createImageModel("hunyuan-image");
const res = await imageModel.generateImage({
  model: "HY-Image-3.0-Plus-4090-Tob-v1.0",
  // 重点：引导AI进行现代设计重构
  prompt: "提取土家族西兰卡普传统鸟纹，转化为极简几何徽章Logo，街头潮流风格，扁平化矢量图，适合作为服装胸前印花，纯白背景",
  size: "1024x1024",
  revise: { value: true },
  timeout: 120000, 
});
console.log(res.data[0].url);
```

### A.3 图生图实现（核心链路）

图生图使用 `HY-Image-v3.0-I2I-ToB-v1.0.1`，垫图通过 `image_urls` 或 `images` 传入。**传base64时绝对不能带 `data:image/...;base64,` 前缀，否则返回400错误。**

```javascript
async pickAndGenerate() {
  const { tempFiles } = await wx.chooseMedia({ count: 1, mediaType: ["image"] });
  const { fileID } = await wx.cloud.uploadFile({
    cloudPath: `ai-input/${Date.now()}.jpg`,
    filePath: tempFiles[0].tempFilePath,
  });
  const { fileList } = await wx.cloud.getTempFileURL({ fileList: [fileID] });

  const imageModel = wx.cloud.extend.AI.createImageModel("hunyuan-image");
  const res = await imageModel.generateImage({
    model: "HY-Image-v3.0-I2I-ToB-v1.0.1",
    // 重点：保留结构，改变风格
    prompt: "保留垫图的西兰卡普菱形构图，转化为现代赛博朋克配色，科技感线条，适合作为潮牌服装印花",
    image_urls: [fileList[0].tempFileURL],
    revise: { value: true },
    timeout: 120000,
  });
  this.setData({ imageUrl: res.data[0].url });
}
```

## B. 服装预览：CSS 绝对定位叠加方案

父容器 `position: relative`，底层为服装 PNG，上层为 AI 纹样，`position: absolute` + `z-index` 控制层级。上层 `opacity` 建议 0.85—0.95。

```xml
<view class="preview-container">
  <image src="{{clothingImage}}" mode="widthFix" class="clothing" />
  <image src="{{patternUrl}}" mode="aspectFit" class="pattern-overlay" />
</view>
```

```css
.preview-container { position: relative; width: 100%; }
.clothing { width: 100%; display: block; }
.pattern-overlay {
  /* 坐标数据必须由霍佳雪提供，此处仅为示例 */
  position: absolute;
  top: 28%; left: 32%; width: 36%; height: 24%;
  opacity: 0.9;
  z-index: 2;
}
```

**Canvas 方案**：仅当需要“导出合成图”时使用。小程序 Canvas 不能直接绘制网络图片，须先用 `wx.getImageInfo` 获取本地路径；导出时 `fileType` 必须设为 `"png"`，因 jpg 不支持透明通道。

## C. 隐私合规（硬性实现要求）

1. 后台完成《用户隐私保护指引》配置，声明收集姓名、电话用途。
2. 表单页必须有用户主动勾选的隐私政策勾选框，不能默认勾选。
3. `app.json` 中显式写入 `"__usePrivacyCheck__": true` 作为审核保险。**不能为绕过开发期报错将其设为 `false` 后忘记改回**——提审前必须恢复为 `true` 或删除该字段。

## D. 视频导览模块的实现要点

`<video>` 的 `src` 和 `poster` 均支持直接传入云文件ID（`cloud://` 格式）。
**约束**：视频体积控制在20MB以内。使用fileID播放云存储视频会消耗账号CDN资源，CDN资源耗尽后视频将无法播放。

## E. WorkBuddy 生成后的必要手动检查项

1. **AI生图调用代码**：确认 `createImageModel` 的 provider 与 `generateImage` 的 `model` 分离正确；确认 `timeout: 120000` 未被遗漏。
2. **`app.json` 中的 `"__usePrivacyCheck__": true`**：WorkBuddy不会自动写入，需手动添加。
3. **`orders` 集合的 `previewImageUrl` 传参链路**：确认从AI工坊到表单页，图片URL确实被携带并写入数据库。
4. **服装预览的定位参数**：AI生成的数值不可用，必须根据霍佳雪提供的坐标手动调整。
5. **图生图base64参数**：若使用 `images` 方式，确认字符串不带前缀。

# 附录：关键模块实现方法

## A. AI定制工坊：文生图与图生图的完整调用

### A.1 前置条件

基础库版本 ≥ 3.17.4，且 CloudBase 环境已完成初始化。未初始化直接调用会报错。

### A.2 文生图实现

`createImageModel("hunyuan-image")` 中的 `"hunyuan-image"` 是 **provider**，真正决定效果的是 `model` 参数。

```javascript
const imageModel = wx.cloud.extend.AI.createImageModel("hunyuan-image");
const res = await imageModel.generateImage({
  model: "HY-Image-3.0-Plus-4090-Tob-v1.0",
  // 重点：引导AI进行现代设计重构
  prompt: "提取土家族西兰卡普传统鸟纹，转化为极简几何徽章Logo，街头潮流风格，扁平化矢量图，适合作为服装胸前印花，纯白背景",
  size: "1024x1024",
  revise: { value: true },
  timeout: 120000, 
});
console.log(res.data[0].url);
```

### A.3 图生图实现（核心链路）

图生图使用 `HY-Image-v3.0-I2I-ToB-v1.0.1`，垫图通过 `image_urls` 或 `images` 传入。**传base64时绝对不能带 `data:image/...;base64,` 前缀，否则返回400错误。**

```javascript
async pickAndGenerate() {
  const { tempFiles } = await wx.chooseMedia({ count: 1, mediaType: ["image"] });
  const { fileID } = await wx.cloud.uploadFile({
    cloudPath: `ai-input/${Date.now()}.jpg`,
    filePath: tempFiles[0].tempFilePath,
  });
  const { fileList } = await wx.cloud.getTempFileURL({ fileList: [fileID] });

  const imageModel = wx.cloud.extend.AI.createImageModel("hunyuan-image");
  const res = await imageModel.generateImage({
    model: "HY-Image-v3.0-I2I-ToB-v1.0.1",
    // 重点：保留结构，改变风格
    prompt: "保留垫图的西兰卡普菱形构图，转化为现代赛博朋克配色，科技感线条，适合作为潮牌服装印花",
    image_urls: [fileList[0].tempFileURL],
    revise: { value: true },
    timeout: 120000,
  });
  this.setData({ imageUrl: res.data[0].url });
}
```

## B. 服装预览：CSS 绝对定位叠加方案

父容器 `position: relative`，底层为服装 PNG，上层为 AI 纹样，`position: absolute` + `z-index` 控制层级。上层 `opacity` 建议 0.85—0.95。

```xml
<view class="preview-container">
  <image src="{{clothingImage}}" mode="widthFix" class="clothing" />
  <image src="{{patternUrl}}" mode="aspectFit" class="pattern-overlay" />
</view>
```

```css
.preview-container { position: relative; width: 100%; }
.clothing { width: 100%; display: block; }
.pattern-overlay {
  /* 坐标数据必须由霍佳雪提供，此处仅为示例 */
  position: absolute;
  top: 28%; left: 32%; width: 36%; height: 24%;
  opacity: 0.9;
  z-index: 2;
}
```

**Canvas 方案**：仅当需要“导出合成图”时使用。小程序 Canvas 不能直接绘制网络图片，须先用 `wx.getImageInfo` 获取本地路径；导出时 `fileType` 必须设为 `"png"`，因 jpg 不支持透明通道。

## C. 隐私合规（硬性实现要求）

1. 后台完成《用户隐私保护指引》配置，声明收集姓名、电话用途。
2. 表单页必须有用户主动勾选的隐私政策勾选框，不能默认勾选。
3. `app.json` 中显式写入 `"__usePrivacyCheck__": true` 作为审核保险。**不能为绕过开发期报错将其设为 `false` 后忘记改回**——提审前必须恢复为 `true` 或删除该字段。

## D. 视频导览模块的实现要点

`<video>` 的 `src` 和 `poster` 均支持直接传入云文件ID（`cloud://` 格式）。
**约束**：视频体积控制在20MB以内。使用fileID播放云存储视频会消耗账号CDN资源，CDN资源耗尽后视频将无法播放。

## E. WorkBuddy 生成后的必要手动检查项

1. **AI生图调用代码**：确认 `createImageModel` 的 provider 与 `generateImage` 的 `model` 分离正确；确认 `timeout: 120000` 未被遗漏。
2. **`app.json` 中的 `"__usePrivacyCheck__": true`**：WorkBuddy不会自动写入，需手动添加。
3. **`orders` 集合的 `previewImageUrl` 传参链路**：确认从AI工坊到表单页，图片URL确实被携带并写入数据库。
4. **服装预览的定位参数**：AI生成的数值不可用，必须根据霍佳雪提供的坐标手动调整。
5. **图生图base64参数**：若使用 `images` 方式，确认字符串不带前缀。
